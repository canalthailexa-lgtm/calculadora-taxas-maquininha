# Calculadora de Taxas de Maquininha

Quanto sobra de verdade em cada venda no cartão: custo da taxa, líquido a receber e
quanto cobrar no cartão para não perder dinheiro.

➡️ **Calculadora no ar:** https://calculadora-taxas-maquininha.streamlit.app/

## Dados de referência

As taxas variam por adquirente, bandeira, prazo e negociação. Para comparar números
reais por adquirente, use o [Índice de Taxas de Maquininhas](https://guiamaquininha.com.br/indice-de-taxas/)
(histórico mensal com fonte oficial por linha).

## Rodar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```
